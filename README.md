# Web Vulnerability Assessment Using Nikto

## 📌 Project Overview
This project demonstrates web vulnerability scanning and security assessment using the Nikto tool in a Linux environment. The objective of this project is to identify common web server vulnerabilities, outdated configurations, and missing security headers.

---

## 🛠️ Tool Used
- Nikto
- Kali Linux

---

##  Objectives
- Perform web server vulnerability scanning
- Identify security misconfigurations
- Detect outdated software and missing headers
- Understand basic penetration testing methodology
- Generate security assessment reports
